# Spending Tracker

A Streamlit web app that categorizes and visualizes spending from a transactions CSV.

## Features
- Upload a CSV of transactions
- Automatic categorization using keyword matching
- Spending breakdown by category (bar chart)
- Total spending summary

## Status
In progress — started as a weekend project alongside a Python learning sprint.

## Tech stack
Python, Streamlit, pandas

## How to run
py -m streamlit run app.py
